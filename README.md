# Financial-Analysis-on-4-SP500-stocks-with-MS-Excel-
Financial analysis on APPLE, NVIDIA, TESLA, AMAZON also comparing them with market (S&P 500)

##  Project Overview
This project is a **10-year financial analysis** comparing **four individual stocks** against the **S&P 500 index**, created using **Microsoft Excel**.  
The analysis focuses on long-term performance trends, returns, and comparative market behavior.

This project demonstrates practical skills in **financial data analysis and Excel-based analytics**.

---

## Data Details
- **Time Period:** Last 10 Years  
- **Assets Analyzed:**
  - 4 Individual Stocks
  - S&P 500 Index (Benchmark)
- **Data Source:** Public historical stock market data
- **Tool Used:** Microsoft Excel

---

## Tools & Techniques
- Microsoft Excel
- Data Cleaning & Organization
- Financial Calculations
- Trend Analysis

---

## Analysis Included
- Stock price trend analysis -> Daily Return, Monthly Return, Annual Return
- Comparison of individual stocks vs S&P 500
- Long-term performance evaluation-> Volatility, Beta, Maximum Drawdown, Sharpe ratio
- Comparative growth and return analysis
